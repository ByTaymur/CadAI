## Scope

This is a point-in-time check for accidental disclosure, not a guarantee that every possible secret or
vulnerability can be detected. Commits show the configured Git author name and email. Repeat the scan after adding
or changing files. `.gitignore` is a preventive aid and does not remove already tracked secrets.
