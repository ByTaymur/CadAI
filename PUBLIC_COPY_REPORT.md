## Scope

This is a point-in-time check for accidental disclosure, not a guarantee that every possible secret or vulnerability can be detected. The preserved Git metadata can include the identity associated with its initial commit. Future commits can also expose the configured Git name/email. No commit, push, remote configuration or online publication was performed.

Local settings, test logs, scanner reports and audit tools are outside this folder. Only this public copy should be used for publication; repeat the scan after adding or changing files. `.gitignore` is a preventive aid and does not remove already tracked secrets.
